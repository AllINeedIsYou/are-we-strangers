# Are We Strangers?

**Мы столько знаем друг о друге. Мы теперь чужие?**

Концепция мессенджера, в котором у каждого разговора есть главы.

</div>

---

**Are We Strangers?** — мессенджер, в котором сохраняется история близости, даже когда сама близость исчезает.

Здесь остаются тысячи сообщений, фотографии, голосовые — следы того, как люди были близки. Всё можно найти поиском. А на вопрос, кем вы стали друг другу, переписка ответить не может.

Поэтому у каждого разговора здесь есть главы.

В одной вы только знакомитесь. В другой — отправляете голосовые спросонья и рассказываете то, чего больше никто не знает. А у какой-то главы последнее сообщение годами остаётся без ответа.

## У разговора есть своё время

### 01 / Быть рядом

Сообщения, звонки, фотографии и голосовые складываются в общую историю. Внутри главы вы можете вместе выбрать моменты для её обложки: несколько слов и снимков, которые хочется сохранить.

*«Лето, когда мы не спали».*

### 02 / Закрыть главу

Когда возвращаться в чат становится тяжело, главу можно закрыть для себя. Она уйдёт из активных разговоров, а переписка сохранится. Для этого не нужно согласие другого человека; его доступ к истории останется прежним.

Всё, что трудно удалить и больно видеть каждый день, останется на своём месте в прошлом.

### 03 / Начать снова

Если однажды захочется вернуться, можно отправить приглашение в новую главу — одну фразу, для которой наконец нашлись слова.

Получатель сам решит, принять его или оставить без ответа. Если вы оба согласитесь, откроется чистый диалог. Прежняя история останется доступной отдельно.

Вы сможете узнавать друг друга заново — с осторожностью людей, которые помнят, как однажды уже были близки.

## Что остаётся за вами

- **Память.** Закрытая глава сохраняет сообщения, фотографии и голоса.
- **Дистанция.** Каждый может убрать разговор из своей повседневной жизни.
- **Выбор.** Новая глава начинается только по обоюдному согласию.

Это место и для друзей, которые разъехались, и для семьи, и для тех, кто однажды не смог договорить. Для любой связи, у которой есть прошлое и пока неизвестное будущее.
